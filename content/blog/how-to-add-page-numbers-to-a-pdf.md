A document without page numbers is hard to discuss. “Look at the table on page 14” only works when page 14 says so. Reports, contracts, theses, manuals and printed handouts all need numbers, yet many PDFs are created without them, or are merged from several files that each start at one.

You can add the numbers afterwards. This guide explains where to put them, how to start counting from the right page, which formats are available and how to check that nothing was covered up.

:::takeaways
- Page numbers are added to a copy of your PDF; the original is not changed.
- Choose the position, the number format and which pages to number.
- Set “First page to number” to 2 to skip a cover page.
- The numbers are drawn on top of each page, so keep margins free of content.
- Merge your files first and number them once, so the sequence is continuous.
:::

## When to add page numbers

- A report was exported without footers.
- You merged several PDFs and each part starts at page 1.
- A scan of a printed document has no numbers at all.
- A contract needs numbering so that nobody can claim a page was removed.
- You are printing handouts and want readers to find pages quickly.

If your source is a word processor, adding numbers there is usually better, because the layout adapts. For a finished PDF, the approach in this guide is the practical option.

## How to number a PDF in your browser

1. Open the tool and add your PDF (up to 100 MB). Unlock it first if it is password-protected.

3. Choose the format, such as a plain number or a longer form with the total.
4. Choose which pages to number, and which number the first numbered page should show.
5. Add the numbers and download the PDF.

## Choosing the position

The usual places are the bottom centre, the bottom outer corner and the top right. Think about how the document will be used:

- Documents that are printed double-sided read best with numbers on the outer corners, so they are easy to find when flicking through.
- Single-sided documents and screen reading work well with the bottom centre.
- A header position is useful when the bottom of the page is crowded with footers or a signature block.

Look at a sample page before you decide. If a page already has a footer, a number placed over it will collide with the text. The numbers are always drawn on top of the page and never behind existing content, so they cannot hide themselves, but they can cover something.

## Number formats

Formats are about how much information the number carries:

- A plain number: 7.
- A number with the total: 7 of 42. This is useful for contracts, because a missing page is obvious.
- A number with a label, such as Page 7.

Pick the one that matches the document’s purpose. A formal agreement benefits from “7 of 42”, a handout rarely needs more than the number.

The tool writes the numbers in Helvetica, which covers digits and Latin letters. That is enough for any numbering format, even in documents written in other alphabets.

## Skipping the cover page

Many documents have a cover or title page that should not carry a number. Set “First page to number” to 2. You can also choose which number that page should show: if the cover is page 1 and the first numbered page should read 1 as well, start counting from 1 there.

The same idea works for a table of contents, a preface or appendices: number only the range you need, and leave the rest empty. If you need different numbering styles in different parts, number the parts separately and then combine them with <tool_merge_pdf>Merge PDF</tool_merge_pdf>.

## Merged documents: number last

When you combine files, the order of operations decides whether the numbering is continuous. Merge first and number second. Our guide to <post_how-to-merge-pdf-files>merging PDF files</post_how-to-merge-pdf-files> explains how to set the order, and then <tool_add_page_numbers>Add Page Numbers</tool_add_page_numbers> counts through the whole result.

If you number first and merge afterwards, every part restarts at one. That can be what you want, for example for separate chapters, but it is rarely right for a single report.

## Rotated pages

Numbers are placed relative to what you see on screen, including pages that are rotated, so a landscape page gets its number in the visible bottom corner. If a page is lying on its side because of a wrong rotation, fix it first with <tool_rotate_pdf>Rotate PDF</tool_rotate_pdf> and then add the numbers. Our guide to <post_how-to-rotate-pdf-pages-permanently>rotating PDF pages permanently</post_how-to-rotate-pdf-pages-permanently> explains how.

## What to check afterwards

- Open the new file and scroll through every page, not only the first.
- Look for a number that sits on top of a footer, a table or a logo.
- Check that the first numbered page shows the number you expect.
- Check the last page, especially if you use the “of total” format.
- Compare the file size with the original. Adding numbers should barely change it; if the file is large, <tool_compress_pdf>Compress PDF</tool_compress_pdf> can help.

## Page numbers and other stamps

Page numbers and watermarks are both drawn on top of the page. If you also need a CONFIDENTIAL stamp or a logo across the pages, use <tool_watermark_pdf>Watermark PDF</tool_watermark_pdf>, and number the pages in a separate step. Doing them separately lets you correct one without redoing the other.

## Common mistakes to avoid

- Numbering before merging, so each part starts at one.
- Placing the number where a footer already is.
- Forgetting to skip the cover page.
- Not looking at the last pages of the result.
- Saving over the original instead of keeping an unnumbered copy.

## A quick checklist

1. Merge, rotate and extract first, so the page order is final.
2. Choose a position that does not collide with existing content.
3. Choose the format and the first page to number.
4. Download the result and scroll through every page.
5. Keep the unnumbered original.

:::faq Frequently asked questions
Q: Can I start numbering from page 2?
A: Yes. Set the first page to number to 2, and choose which number it should show.

Q: Can I add page numbers to a scanned PDF?
A: Yes. The numbers are drawn on top of each page, whether the page is text or a picture.

Q: Will the numbers appear in the right place on rotated pages?
A: Yes. They are placed relative to what you see on screen, including rotated pages.

Q: Which font is used?
A: Helvetica, which covers digits and Latin letters.

Q: Can I number a password-protected PDF?
A: Not directly. Unlock it first, then add the numbers to the unlocked copy.

Q: Can I remove the numbers later?
A: Not with this tool. The numbers are drawn into the page, so keep the original file if you may need an unnumbered version.
