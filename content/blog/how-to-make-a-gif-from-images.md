An animated GIF is a small silent movie that plays anywhere: in a chat, an email, a help article or a web page. It needs no player and no sound, which makes it perfect for showing a short process, a before and after, a product from several angles or a simple joke.

You do not need video software to make one. This guide shows how to build a GIF from a set of pictures in your browser, how to choose timing, size and looping, and how to keep the file small enough to send.

:::takeaways
- A GIF is a sequence of pictures, called frames, shown one after another with a delay between them.
- Fewer frames, a smaller width and fewer colours all make the file smaller.
- GIFs are limited to 256 colours per frame, so photos can look grainy.
- Transparent areas can be kept, but GIF transparency is on or off for each pixel, so soft edges become hard.
- Animated pictures that you add contribute only their first frame.
:::

## What a GIF is, and when it is the right choice

A GIF stores every frame as a picture and plays them in order. Because every frame is a full picture limited to 256 colours, GIFs are best for simple content: screenshots, diagrams, icons, logos and short sequences with flat colours.

They are less good for long clips and for photographs. A ten-second video clip turned into a GIF is usually much larger than the video and looks worse. For long or detailed motion, a video file is the better choice. For a short, simple loop of three to twenty frames, a GIF is hard to beat because it works everywhere without any player.

## Plan your frames

Good GIFs begin with good preparation.

1. Decide what the loop shows. A before and after needs two frames. A process needs one frame per step. A product turn needs six to twelve frames.
2. Make every frame the same size, or at least the same proportions. If frames differ, the animation jumps.
3. Keep the subject in the same place from frame to frame, so the eye follows the change and not the camera.
4. Name the files in order, such as step-01, step-02 and so on, which makes them easy to add in the right sequence.

## Timing and looping

The delay decides how the animation feels. A short delay, such as a tenth of a second per frame, gives smooth motion if you have many frames. A long delay, such as one or two seconds, suits slides and step-by-step guides where people need time to read.

You can also set a different delay for a frame that deserves attention. Give the last frame of a before and after a longer pause, so the viewer sees the result before the loop restarts.

Looping decides whether the GIF repeats forever or plays a set number of times. Endless loops are the usual choice for decoration, and a limited loop suits instructions that should not distract once they are understood.

## Choosing the size

Width is the biggest lever on file size, because the number of pixels in every frame multiplies by the number of frames.

- For a chat or an email, a width of 480 to 600 pixels is usually plenty.
- For a web page, use the width at which it is displayed.
- Avoid very large GIFs. They are slow to load and heavy on phones.

If a picture is much larger than you need, make it smaller before you build the GIF. <tool_image_resizer>Resize Image</tool_image_resizer> resizes many pictures at once, which also keeps the frames consistent. The tool allows up to 100 frames, and larger frames need more memory in your browser, so use fewer frames when the pictures are large.

## Colours and transparency

A GIF frame has at most 256 colours. Flat graphics fit easily, and photographs show banding, which looks like grainy steps in gradients. Reducing the number of colours makes the file smaller, and with graphics you often see no difference.

If your pictures have transparent areas, such as a PNG logo, turn on the option to keep them. Be aware that GIF transparency is on or off for each pixel. A soft shadow or a smooth edge cannot be partly transparent, so soft edges become hard and can look jagged on some backgrounds.

Animated pictures that you add, such as other GIFs or animated WebP files, contribute only their first frame. To reuse a frame from another animation, export it as a still picture first.

## Making a GIF smaller

When the result is too large, try these in order. They are listed from the most effective to the least.

1. Reduce the width.
2. Use fewer frames. Remove frames that add little to the story.
3. Reduce the number of colours.
4. Crop away parts of the picture that do not change.
5. Shorten the loop.

The tool warns when a GIF is above about 10 MB, which is too large for most chats and emails. A good target for sharing is under 2 or 3 MB. ## Accessibility and good manners

Animation can be distracting. Keep loops short and calm, avoid fast flashing and do not put essential information only in a GIF. Add a text description wherever the GIF appears, so that people who cannot see it, or who have motion switched off, still understand what it shows.

## Common mistakes to avoid

- Using frames of different sizes, which makes the animation jump.
- Using a photo sequence with large pictures and wondering why the file is huge.
- Leaving the delay so short that people cannot read the frames.
- Forgetting that soft transparent edges turn hard in a GIF.
- Making a long clip into a GIF when a video would be smaller and sharper.

## A quick checklist

1. Plan three to twenty frames that tell one clear story.
2. Make the frames the same size and edit them first.
3. Set the order, the delay and the loop.
4. Pick a width suited to where the GIF will be used.
5. Check the file size, and reduce width, frames or colours if needed.
6. Add a text description where you publish it.
