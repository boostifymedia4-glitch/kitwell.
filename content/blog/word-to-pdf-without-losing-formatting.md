A PDF looks the same on every device, which is why people ask for one when you send a CV, a contract, an assignment or an invoice. A Word file can look different on another computer, with different fonts and shifted page breaks. Converting to PDF fixes the look in place.

The catch is that no converter reproduces a Word document exactly unless it is Word itself. This guide explains what a browser-based conversion keeps, what it only approximates, and how to prepare your document so that the PDF comes out as close as possible to what you expect.

:::takeaways
- Word to PDF converts DOCX files; old .doc files and password-protected documents are not supported.
- Text formatting, headings, lists, tables, links and JPEG and PNG pictures are kept.
- Headers, footers, footnotes, text boxes, equations, charts and shapes are not reproduced, and fonts are replaced by Noto Sans.
- The tool lists what it could not convert, so check the result before you send it.
:::

## If you have Word, use its own export first

If Microsoft Word or a compatible office program is installed on your computer, its built-in Save as PDF (or Export) gives the most faithful result, because the same program that laid out the document writes the PDF. Nothing else can do better.

A browser tool is for the other situations: you are on a computer or phone without Word, you only have the file, you do not want to install anything, or you need a quick conversion of a simple document. In those cases <tool_word_to_pdf>Word to PDF</tool_word_to_pdf> does the job, as long as you know its limits.

## How to convert a Word file to PDF

The conversion runs in your browser, so the document is not uploaded anywhere.

1. Open the tool and choose your DOCX file (up to 50 MB).
2. Pick the page size. You can keep the size set in the document or choose another one.
3. Press Convert. The tool reads the document, lays out the pages and builds the PDF.
4. Read the notes under the result. If something could not be converted, they tell you what and how many.
5. Download the PDF and open it before you send it.

## What is kept

The converter reads the content and structure of the document and lays it out again. These parts carry over:

- Bold, italic, underlined text and hyperlinks.
- Headings and paragraph alignment.
- Bullet and numbered lists.
- Tables.
- Pictures in JPEG and PNG format.
- Line breaks, page breaks and the page orientation.

Because the text stays real text, you can select, search and copy it in the PDF.

## What is approximated or left out

Be realistic about these differences, and check them in the result:

- Fonts. The original fonts are replaced by Noto Sans, so line breaks and page breaks will fall in different places than in Word.
- Layout features such as columns and text that wraps around a picture are not reproduced.
- Headers, footers and footnotes are not included.
- Text boxes, equations, charts, shapes and pictures in formats other than JPEG and PNG are skipped.
- Scripts that Noto Sans does not cover, such as Arabic, Hebrew, Thai, Chinese, Japanese and Korean, appear as question marks. The tool tells you how many characters were affected.

The tool counts what it skipped and says so under the result, so you are never left guessing why a table or a picture is missing.

## Prepare the document for a cleaner PDF

A few minutes of preparation in Word makes the PDF better:

1. Use real headings and lists instead of manual spacing and typed bullets. Structure converts well; hand-drawn spacing does not.
2. Put pictures in line with the text, and save them as JPEG or PNG. Floating pictures and other formats may not carry over.
3. Move important information out of headers, footers and text boxes into the main text.
4. Replace special equations or charts with a picture saved as PNG or JPG.
5. Save the file in the current DOCX format. If your file is an old .doc, open it in Word and use Save As, then choose DOCX.

> Tip: convert a short test first. If the first page looks right, the rest almost always will too.

## Page size: keep the document’s or choose one

By default the PDF uses the page size stored in the document, such as A4 or Letter. If you are sending the file to a country or office that prints on the other standard, choose it explicitly. Remember that a different page size also changes where lines and pages break.

## Troubleshooting

- The tool says the file is not a valid document: check that it is really a DOCX and not an old .doc renamed, and that it is not password-protected.
- Pages break in different places than in Word: that is expected, because the fonts differ. Adjust the page size or spacing in Word and convert again.
- A picture is missing: it was probably in an unsupported format or inside a text box. Re-insert it in line with the text as a JPEG or PNG.
- Text shows question marks: the characters are in a script the tool does not support yet.

:::faq Frequently asked questions
Q: Will the PDF look exactly like my Word document?
A: Not exactly. The tool does not use Microsoft Word, so fonts, spacing and page breaks differ. It reproduces the content and structure, not the exact layout, so check the result before you send it.

Q: Can I convert an old .doc file?
A: Not directly. Open it in Word, save it as a DOCX file and convert that.

Q: Is my document uploaded to a server?
A: No. The conversion runs in your browser tab and the file stays on your device.

Q: Can I convert a password-protected document?
A: No. Remove the protection in Word first, then convert the document.

Q: Why is the text in my PDF a different font?
A: The original fonts are replaced by Noto Sans so that the PDF can be built in the browser. This is also why line and page breaks can move.
:::
